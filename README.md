 Mahakumbh 2025, RCB stampede incident make me to work on this project. Prevent tragic stampedes and overcrowding incidents (like Mahakumbh 2025, RCB stampede) through real-time AI monitoring.

## Step 1: Clone the Repository
1. git clone https://github.com/DIVY3200/Crowd-Management-System-Using-AI-and-ML.git
2. cd Crowd-Management-System-Using-AI-and-ML

## Step 2: Create & Activate Virtual Environment
### For Windows (PyCharm / CMD / PowerShell)
1. python -m venv crowd_env
2. crowd_env\Scripts\activate

### For Linux / Mac
1. python3 -m venv crowd_env
2. source crowd_env/bin/activate

## Step 3: Install Required Libraries
pip install -r requirements.txt

## Step 4: Download YOLO Model Weights
Make sure these files are present in the project folder:

1. yolov8n.pt
2. yolov8s.pt

## Step 5: Run the Crowd Management System
python crowd_management_system.py
